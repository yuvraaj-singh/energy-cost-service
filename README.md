# energy-cost-service
Helps to calculate cost related to Enegry Consumption for a household

Fetches realtime usage data from Lyse Energy apis and calculates the costs related to usage for previous days

## Problem
The Lyse Energy service website currently doesn't support calculating the real-time costs associated with the usage. Hence this service aims to pull the usage and calculates the cost based on the prices given by the older Lyse Faktura.
